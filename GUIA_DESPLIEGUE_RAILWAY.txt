-------------------------------------

8. SOLUCIÓN DE PROBLEMAS
================================================================================

PROBLEMA 1: "Build Failed - .NET SDK not found"
------------------------------------------------
SOLUCIÓN:
- Verifica que nixpacks.toml existe en la raíz del repositorio
- Verifica que contiene: nixPkgs = ["dotnet-sdk_8"]
- Redespliega desde la pestaña Deployments

PROBLEMA 2: "Database connection failed"
-----------------------------------------
SOLUCIÓN:
- Ve a Variables y verifica que las variables de MySQL están presentes
- Verifica que MYSQLHOST, MYSQLPORT, etc. tienen valores
- Verifica que el servicio MySQL está corriendo (debe estar verde)
- Redespliega el backend

PROBLEMA 3: "Port already in use"
----------------------------------
SOLUCIÓN:
- Railway asigna el puerto automáticamente en la variable $PORT
- Verifica que Program.cs usa Environment.GetEnvironmentVariable("PORT")
- No hardcodees el puerto en ningún lado

PROBLEMA 4: "CORS error en el frontend"
----------------------------------------
SOLUCIÓN:
- Verifica que el dominio del frontend está en la lista de CORS en Program.cs
- Agrega el dominio exacto en WithOrigins()
- Redespliega el backend

PROBLEMA 5: "SignalR no conecta"
---------------------------------
SOLUCIÓN:
- Verifica que el endpoint /hubs/maquinas está accesible
- Prueba: https://TU-DOMINIO.up.railway.app/hubs/maquinas
- Verifica que WebSockets están habilitados en Railway (lo están por defecto)
- Revisa los logs del navegador (F12 → Console)

PROBLEMA 6: "Application crashed"
----------------------------------
SOLUCIÓN:
- Ve a Deployments → Logs
- Busca el error específico
- Errores comunes:
  * Missing environment variable → Agrega la variable
  * Database connection → Verifica MySQL está corriendo
  * Port binding → Verifica que usas $PORT

PROBLEMA 8: "Railway no encuentra el proyecto .NET"
----------------------------------------------------
SOLUCIÓN:
- Verifica que configuraste el Root Directory correctamente
- Pasos:
  1. Haz clic en tu servicio backend
  2. Ve a "Settings"
  3. Busca la sección "Source" (al principio)
  4. Debe mostrar "Root Directory: backend"
  5. Si no está, haz clic en "Add Root Directory"
  6. Escribe: backend
  7. Railway redesplegará automáticamente

PROBLEMA 9: "Build falla con 'No .csproj found'"
-------------------------------------------------
SOLUCIÓN:
- El Root Directory no está configurado o está mal escrito
- Debe ser exactamente: backend (sin / al final, sin mayúsculas)
- Verifica en Settings → Source → Root Directory
- Si está mal, corrígelo y Railway redesplegará

PROBLEMA 10: "No veo la opción 'Add Root Directory'"
-----------------------------------------------------
SOLUCIÓN:
- Si ya hay un Root Directory configurado, verás el valor actual
- Para cambiarlo, haz clic en el valor actual
- Aparecerá un campo de texto donde puedes editarlo
- Si no ves nada, busca en Settings → Source (primera sección)
