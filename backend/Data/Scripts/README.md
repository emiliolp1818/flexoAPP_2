# 📊 Data/Scripts - Scripts de Datos Iniciales

Scripts para poblar la base de datos con datos iniciales y de ejemplo.

---

## 📋 Scripts Disponibles

### 1. `00_SetupDatabase.sql`
Script de configuración general de la base de datos.

### 2. `SETUP_COMPLETE_DATABASE.sql`
Script completo de configuración de todas las tablas.

### 3. `CrearYPoblarTablaMaquinas.sql`
Crea y puebla la tabla de máquinas con datos de ejemplo.

### 4. `create_condicionunica_flexoBD.sql`
Crea la tabla de condiciones únicas.

### 5. `QUICK_FIX_COLORS.sql`
Script de corrección rápida para colores en diseños.

---

## 🚀 Uso

Estos scripts se usan para:
- Poblar base de datos con datos de ejemplo
- Crear tablas específicas
- Correcciones rápidas de datos

---

## ⚠️ Importante

- **Revisar datos** antes de ejecutar en producción
- **Adaptar datos de ejemplo** según necesidades
- **Hacer backup** antes de ejecutar scripts de corrección

---

## 📝 Notas

Los datos de ejemplo son útiles para:
- Desarrollo y pruebas
- Demostración del sistema
- Entrenamiento de usuarios
