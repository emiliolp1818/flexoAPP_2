#### Opción 2: Configurar Personal Access Token (PAT)
1. Ve a GitHub.com → Settings → Developer settings → Personal access tokens
2. Genera un nuevo token con permisos de "repo"
3. Copia el token
4. Ejecuta en terminal:
   ```bash
   git push https://[TU_TOKEN]@github.com/emiliolp1818/flexoAPP_2.git main
   ```

1. Configura SSH keys en GitHub
2. Cambia el remote a SSH:
   ```bash
   git remote set-url origin git@github.com:emiliolp1818/flexoAPP_2.git
   git push origin main
   ```

#### Opción 4: Usar Git Credential Manager
1. Ejecuta:
   ```bash
   git config --global credential.helper manager
   git push origin main
   ```
2. Se abrirá una ventana para autenticarte con GitHub
