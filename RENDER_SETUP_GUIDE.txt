1. PREPARACIÓN DEL REPOSITORIO
===============================================================================

1.1 CREAR CUENTA EN RENDER
   - Ir a: https://render.com
   - Registrarse con GitHub (recomendado)
   - Conectar tu repositorio: https://github.com/emiliolp1818/flexoAPP_2

1.2 ESTRUCTURA DEL PROYECTO
   Verificar que tienes esta estructura:
   
   flexoAPP_2/
   ├── backend/                 # API .NET Core
   │   ├── flexoAPP.csproj
   │   ├── Program.cs
   │   ├── appsettings.json
   │   └── ...
   ├── Frontend/                # Angular App
   │   ├── package.json
   │   ├── angular.json
   │   └── src/
   ├── Dockerfile              # Para el backend
   └── render.yaml             # Configuración de Render

2. CONFIGURACIÓN DE BASE DE DATOS
===============================================================================

2.1 CREAR BASE DE DATOS EN RENDER
   - En Render Dashboard → "New" → "PostgreSQL"
   - Name: flexoapp-database
   - Database Name: flexoapp_db
   - User: flexoapp_user
   - Region: Oregon (US West) - más barato
   - Plan: Free (para testing)

2.2 OBTENER DATOS DE CONEXIÓN
   Render te dará:
   - Host: [algo].render.com
   - Port: 5432
   - Database: flexoapp_db
   - Username: flexoapp_user
   - Password: [generado automáticamente]
   
   IMPORTANTE: Guarda estos datos, los necesitarás para el backend.

2.3 STRING DE CONEXIÓN
   Formato para .NET Core:
   Host=[host];Port=5432;Database=flexoapp_db;Username=flexoapp_user;Password=[password];SSL Mode=Require;

3. CONFIGURACIÓN DEL BACKEND (API .NET CORE)
===============================================================================

3.1 CREAR SERVICIO WEB EN RENDER
   - En Render Dashboard → "New" → "Web Service"
   - Connect Repository: flexoAPP_2
   - Branch: render (o main)
   - Name: flexoapp-backend
   - Region: Oregon (US West)
   - Environment: Docker
   - Dockerfile Path: Dockerfile

3.2 CONFIGURACIÓN DEL SERVICIO
   Build Command: (dejar vacío - usa Dockerfile)
   Start Command: (dejar vacío - usa Dockerfile)

3.3 VARIABLES DE ENTORNO DEL BACKEND
   Agregar estas variables en Render:

   ASPNETCORE_ENVIRONMENT = Production
   
   ConnectionStrings__DefaultConnection = 
   Host=[TU_HOST_DB];Port=5432;Database=flexoapp_db;Username=flexoapp_user;Password=[TU_PASSWORD];SSL Mode=Require;
   
   JwtSettings__SecretKey = FlexoAPP-Super-Secret-Key-2024-Production-Ready-Ultra-Stable
   JwtSettings__Issuer = FlexoAPP
   JwtSettings__Audience = FlexoAPP-Users
   JwtSettings__ExpirationMinutes = 1440
   
   PORT = 10000
   ASPNETCORE_URLS = http://+:10000

3.4 CONFIGURACIÓN AVANZADA
   - Health Check Path: /health
   - Auto-Deploy: Yes
   - Plan: Free (para testing)

4. CONFIGURACIÓN DEL FRONTEND (ANGULAR)
===============================================================================

4.1 CREAR SERVICIO ESTÁTICO EN RENDER
   - En Render Dashboard → "New" → "Static Site"
   - Connect Repository: flexoAPP_2
   - Branch: render (o main)
   - Name: flexoapp-frontend
   - Root Directory: Frontend

4.2 CONFIGURACIÓN DE BUILD
   Build Command: npm ci && npm run build:render
   Publish Directory: dist/flexoapp

4.3 VARIABLES DE ENTORNO DEL FRONTEND
   NODE_ENV = production
   ANGULAR_ENV = render

4.4 ACTUALIZAR ENVIRONMENT.RENDER.TS
   En Frontend/src/environments/environment.render.ts:
   
   export const environment = {
     production: true,
     apiUrl: 'https://flexoapp-backend.onrender.com/api',
     socketUrl: 'https://flexoapp-backend.onrender.com',
     // ... resto de configuración
   };

5. ARCHIVOS DE CONFIGURACIÓN NECESARIOS
===============================================================================

5.1 DOCKERFILE (raíz del proyecto)
   FROM mcr.microsoft.com/dotnet/sdk:8.0 AS build-env
   WORKDIR /app
   
   COPY backend/*.csproj ./
   RUN dotnet restore
   
   COPY backend/ ./
   RUN dotnet publish -c Release -o out
   
   FROM mcr.microsoft.com/dotnet/aspnet:8.0
   WORKDIR /app
   COPY --from=build-env /app/out .
   
   RUN mkdir -p logs uploads
   
   ENV ASPNETCORE_ENVIRONMENT=Production
   ENV ASPNETCORE_URLS=http://+:10000
   EXPOSE 10000
   
   ENTRYPOINT ["dotnet", "FlexoAPP.API.dll"]

5.2 RENDER.YAML (opcional pero recomendado)
   services:
     - type: web
       name: flexoapp-backend
       env: docker
       dockerfilePath: Dockerfile
       envVars:
         - key: ASPNETCORE_ENVIRONMENT
           value: Production
         - key: PORT
           value: 10000
       healthCheckPath: /health
     
     - type: static
       name: flexoapp-frontend
       buildCommand: npm ci && npm run build:render
       publishDir: dist/flexoapp
       rootDir: Frontend

===============================================================================
7. TROUBLESHOOTING COMÚN
===============================================================================

7.1 ERRORES DE BASE DE DATOS
   - Verificar string de conexión
   - Verificar que la DB esté "Available"
   - Verificar SSL Mode=Require

7.2 ERRORES DE BACKEND
   - Verificar Dockerfile
   - Verificar variables de entorno
   - Revisar logs en Render Dashboard

7.3 ERRORES DE FRONTEND
   - Verificar que npm run build:render funcione localmente
   - Verificar environment.render.ts
   - Verificar publishDir: dist/flexoapp

7.4 ERRORES DE CONEXIÓN
   - Verificar CORS en backend
   - Verificar URLs en environment.render.ts
   - Verificar que backend esté corriendo
