╔══════════════════════════════════════════════════════════════════════════╗
║                         DESCRIPCIÓN GENERAL                              ║
╚══════════════════════════════════════════════════════════════════════════╝

FlexoAPP es un sistema de gestión flexográfica completo con arquitectura 
cliente-servidor, diseñado para gestionar máquinas, pedidos, diseños y 
documentos en la industria flexográfica.

El proyecto utiliza tecnologías modernas y está dividido en dos componentes 
principales:
  - Backend: API REST desarrollada en ASP.NET Core 8.0 (C#)
  - Frontend: Aplicación web desarrollada en Angular 20.3.x (TypeScript)
